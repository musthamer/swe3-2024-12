Termin bestätigen

Geben Sie die Buchungs-ID ein oder scannen Sie den QR-Code des Patienten.

Hinweis zur QR-Code-Nutzung:

Die QR-Codes auf den Terminbestätigungen der Patienten können nur von angemeldeten Administratoren gescannt werden.

  1. Stellen Sie sicher, dass Sie als Administrator angemeldet sind.
  2. Scannen Sie den QR-Code mit einer Kamera oder einem QR-Code-Scanner.
  3. Der QR-Code führt Sie direkt zum Admin-Dashboard und zeigt die Termindetails an.
  4. Überprüfen Sie die Daten und bestätigen Sie den Termin mit dem Button "Impfung als durchgeführt markieren".
